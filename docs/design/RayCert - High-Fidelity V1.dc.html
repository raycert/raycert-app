Option A — Tap = Submit

Option B — Select + Confirm
Đâu là thủ đô VN?
A. Hà Nội (selected)
B. TP.HCM
Gửi câu trả lời
Tap chọn → state Selected → xác nhận bằng CTA riêng → mới Submitted/Locked.
+ Cho phép đổi ý trước khi gửi, tránh bấm nhầm — phù hợp bối cảnh đào tạo/chứng chỉ
− Thêm 1 bước, chậm hơn 1 nhịp
Quyết định: Option B — Select + Confirm, áp dụng nhất quán cho cả QUIZ và POLL. Lý do: RayCert dùng cho đào tạo/certify — sai một câu có thể ảnh hưởng kết quả đánh giá, nên ưu tiên tránh bấm nhầm hơn tốc độ tối đa. "Gửi câu trả lời" cũng là 1 CTA rõ ràng, dễ nhận biết trên mobile hơn so với việc mọi option đều là "nút submit ngầm". Timer vẫn tạo áp lực thời gian hợp lý mà không cần tap=submit.

Final Notes

Final Screen Inventory
25 màn hình hi-fi: Trainer (1–7) · Host (8–14) · Participant (15–23) · Reporting (24–25). Submitted State (20) là state của Answer screen, không route riêng. Số thứ tự khớp với Wireframe V1 sau khi thêm Import Excel Panel và tách Host Question theo QUIZ/POLL.
Component Inventory (cập nhật)
Button (primary/secondary/ghost), Input, Textarea, Select, Card, Modal, Tabs, Sidebar item, Badge (QUIZ/POLL), Timer, Progress, Toast — theo Design System V1, không đổi.
Answer Option — thêm state Selected-pending-confirm (mới, do Select+Confirm pattern) trước Submitted/Locked.
Image Upload — mới: Empty, Hover/dropzone, Uploading, Preview, Replace, Remove, Error. Dùng chung cho QUIZ & POLL, không có ở answer option.
Excel Import Preview Table — mới: row/type/question/status/error, không tái dùng nơi khác.
Result Bar, Leaderboard Row — không đổi so với Design System V1.
Reconnecting Overlay / Reconnect Failed — mới: overlay tối phủ toàn màn hình, không chặn hẳn navigation gốc (participant vẫn thấy context phía sau).
Design Decisions
Interaction pattern: Select + Confirm cho cả QUIZ và POLL (xem mục đầu trang).
Host Question thứ tự: progress/badge → timer/response → question text → optional image → answer options → End Question.
Image: contain + max-height, không crop; nếu quá cao, question + phần đầu answer options vẫn ưu tiên hiển thị hơn ép toàn bộ vào 1 viewport.
POLL 5–6 option: cho phép scroll dọc có kiểm soát trong khung answer list, CTA gửi câu trả lời neo cố định.
Host screens dùng nền navy đậm (brand-900) riêng biệt với Trainer Dashboard (nền sáng) để phân định rõ "chế độ trình chiếu" — không phải màn hình quản trị.
Unresolved Questions
Participant có cần xem Leaderboard giữa game, hay chỉ Host mới thấy? (hiện tại: chỉ Host — cần xác nhận).
Excel template: có cần hỗ trợ cột ảnh (link ảnh) trong lần import đầu, hay ảnh luôn add tay sau import?
Tablet layout cho Quiz Editor: sidebar-drawer đã đề xuất ở Wireframe — cần hi-fi riêng hay đủ dùng bản desktop scale down?
